## Project Overview
The TEDx KFUPM website was designed to support one of the leading student-led TEDx events in Saudi Arabia. The website serves as the primary digital platform for attendees, speakers, and organizers, providing clear access to event information, speaker details, schedules, and registration.

The main objective was to create a clean, engaging, and user-friendly experience while strictly following the **official TEDx visual identity guidelines**, ensuring consistency with global TEDx branding.

---

## Design Goals
- Apply **TEDx global visual identity** consistently across all pages  
- Deliver a clean, modern, and professional interface  
- Improve clarity of event information and content hierarchy  
- Enhance usability and navigation for different user types  
- Ensure responsive design across desktop, tablet, and mobile  

---

## Target Users
- Event attendees  
- Speakers and guests  
- Organizers and partners  
- General visitors interested in TEDx KFUPM  

---

## UX Process
- Analyzed event requirements and content needs  
- Designed low-fidelity wireframes to define layout and user flow  
- Created high-fidelity UI designs using Figma  
- Focused on visual hierarchy, readability, and accessibility  
- Iterated designs based on feedback from technical and content teams  

---

## Key UI/UX Contributions
- Designed the full website UI following **TEDx branding guidelines**  
- Created structured layouts for:
  - Event overview  
  - Speakers section  
  - Agenda and schedule  
  - Registration and contact information  
- Applied consistent typography, color palette, and spacing  
- Designed clear call-to-action elements for registration  
- Ensured usability and responsiveness across screen sizes  
- Collaborated closely with developers and organizers to align design and implementation
